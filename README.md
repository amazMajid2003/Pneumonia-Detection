
# 🫁 Pneumonia Detection Using Deep Learning and GANs

## 📖 Project Summary

Pneumonia is a severe lung infection that can be detected through chest X-ray images. This project aims to build a **deep learning-based system** that can automatically detect whether a person has pneumonia or not by analyzing their chest X-ray. To improve the performance of detection, the project uses **pre-trained CNN models** like VGG16, MobileNetV2, ResNet50, and DenseNet121.

To further enhance model performance and address class imbalance, **Generative Adversarial Networks (GANs)** are used to generate synthetic X-ray images. A **Flask web application** is also developed where users can upload X-ray images and get instant pneumonia predictions.

---

## 📦 Dataset

### 📌 Source:
The dataset used in this project is from **Kaggle**, titled:  
**[Chest X-Ray Images (Pneumonia)](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia)**

### 📁 Structure:
The dataset contains two main classes:

- **Normal** (Healthy X-ray images)
- **Pneumonia** (X-ray images of patients with pneumonia)

Each class is split into three subsets:
- `train`
- `val`
- `test`

### 🧹 Preprocessing:
- Images were resized to a consistent shape for input into CNN models.
- Applied normalization to bring pixel values in the range [0, 1].
- Data augmentation was performed to reduce overfitting, including:
  - Rotation
  - Horizontal flipping
  - Zooming
  - Brightness adjustment

---

## 🧠 Deep Learning Models

The following **pre-trained CNN architectures** were fine-tuned on the chest X-ray dataset:

| Model        | Description |
|--------------|-------------|
| **VGG16**    | A deep CNN model with 16 layers, known for its simplicity and effectiveness. |
| **MobileNetV2** | A lightweight CNN architecture optimized for mobile and embedded vision applications. |
| **ResNet50** | A deep residual network with 50 layers that uses skip connections to train very deep networks. |
| **DenseNet121** | A CNN where each layer connects to every other layer, improving efficiency and feature reuse. |

These models were trained **first on the original dataset**, and then **retrained with additional synthetic images** generated by GANs.

---

## 🌈 GAN (Generative Adversarial Network)

To improve performance, especially in cases where data was limited or imbalanced:

- A **GAN model** was trained separately for each class (Normal and Pneumonia).
- The generator learned to create realistic-looking chest X-ray images.
- These synthetic images were added to the original dataset, increasing the number of training examples and helping the models generalize better.

GANs helped solve:
- **Data imbalance**
- **Overfitting**
- **Limited diversity in real-world examples**

---

## 🌐 Flask Web Application

A simple and interactive **Flask web app** was created to make the pneumonia detection system accessible to end-users.

### 🖼️ Features:
- Upload a chest X-ray image (in JPG/PNG format)
- Automatically run prediction using the trained model
- Display result: **"Normal"** or **"Pneumonia"**
- Show confidence/probability score
- User-friendly interface

### 🏃‍♂️ Run the Web App:

```bash
python app.py
```

Then open your browser and go to: [http://127.0.0.1:5000](http://127.0.0.1:5000)

## 📊 Model Performance

All models showed strong performance, especially after training on the GAN-augmented dataset.

| Model        | Accuracy | Precision | Recall | F1 Score |
|--------------|----------|-----------|--------|----------|
| VGG16        | 96.2%    | 95.8%     | 97.1%  | 96.4%    |
| MobileNetV2  | 95.1%    | 94.5%     | 96.0%  | 95.2%    |
| ResNet50     | 96.8%    | 96.3%     | 97.4%  | 96.8%    |
| DenseNet121  | 97.3%    | 97.0%     | 98.1%  | 97.5%    |
